# EvoZeus-CoEvolve v0.15.1

v0.15.1 修复一个影响所有会话的问题：只要有一个已登记的 Skill 找不到（例如仓库挪了位置），启动检查就会拦住每一个 Codex 会话。现在会先跳过找不到的 Skill，照常开始工作，并给出一条真实可用的修复命令。

## 变更摘要

- 登记失效或不一致时不再拦截会话；用户只看到一行业务语言提示和修复命令。
- 新增 `--repair-projects`：按登记文件或 git `origin` 找回挪走的仓库；默认只预览，加 `--apply` 才改指；找到多个位置时列出让人选，找不到时给出删除命令。
- 一切正常、无法确认最新版本、或只是 Harness 落后时，启动不再显示任何提示；落后信息只给 Agent，用户要求维护该 Skill 时才提一句。

## 兼容性

- 目标 Repo 的 Harness 版本仍为 `v0.15.0`，不需要迁移。
- 与 EvoZeus Core `v0.5.3` 搭配时，健康启动完全静默；与旧版 Core 搭配时，健康启动可能显示一行无害的 `[EvoZeus <渠道>] CoEvolve hook evaluated.`。

## 验证范围

- `python3 scripts/evozeus_test.py -q` 通过。
- 手动验证：模拟仓库搬家后，预览找到新位置，`--apply` 改指成功，下一次启动检查静默。
- 未在已安装的 UAT 运行时中做端到端验证。
